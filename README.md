# Pink Cursive To-Do List App

A beginner-friendly HTML, CSS, and JavaScript project with a pink gradient background and cursive typography.

## Features
- Add tasks with a scheduled time
- Display task and time together
- Sort tasks by time
- Mark tasks complete and delete them
- Save tasks in browser localStorage
- Responsive layout

## Run locally
Open `index.html` in a modern web browser. The cursive Google Font loads when internet access is available; fallback cursive fonts are included.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of your repository, commit the changes, and enable GitHub Pages from the repository's Settings if it is not already enabled.
